**Data-driven coachmarks and onboarding tours that install with their own Agent Skills.**

Drop it into any React 18+ app: declare chapters, selectors, topics and copy as config, and `npm install` also generates `SKILL.md` files in your project so an AI agent knows how to author and embed tours immediately. Zero app-specific coupling, CSS-variable theming, TypeScript-first, MIT.
